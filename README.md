# python_course_solutions

Решения задач курса **«Программирование на Python»** на Stepik: https://stepik.org/a/289270

В репозитории собраны все 115 задач курса с кодом: условие и решение, которое проходит проверку на Stepik. Репозиторий нужен, чтобы после решения задачи можно было сравнить свой код с вариантом автора курса.

## Как пользоваться

1. Сначала решите задачу сами и отправьте решение на Stepik.
2. Найдите файл задачи: папка модуля → папка урока → `step_NN.py`, где `NN` — номер шага в уроке.
3. Сравните решения. Если они отличаются, это нормально: у большинства задач несколько правильных решений. Подумайте, чем ваш вариант лучше или хуже.

Если задача не получается, не открывайте решение сразу. Перечитайте теорию урока, запустите код на своих данных, посмотрите комментарии под шагом на Stepik. Подсмотренное решение почти ничему не учит.

## Как устроен файл задачи

```python
r"""
Урок «Арифметические операции», шаг 2
https://stepik.org/lesson/2493448/step/2

Условие задачи...
"""

a = int(input())
b = int(input())
print(a * b)
```

В начале файла — урок, номер шага и ссылка на него, затем условие. Ниже — решение.

## Как запустить решение

Нужен Python 3.10 или новее. Решения читают входные данные через `input()`, как на Stepik:

```bash
python 01_basics/03_arithmetic/step_02.py
```

После запуска введите данные с клавиатуры, по одному значению в строке. Можно передать их и сразу:

```bash
printf "5\n3\n" | python 01_basics/03_arithmetic/step_02.py
```
